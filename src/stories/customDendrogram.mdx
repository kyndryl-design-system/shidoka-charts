# Custom Dendrogram

A from-scratch Chart.js plugin (`customDendrogram`) that renders dendrogram-style trees on a Chart.js canvas. It is registered automatically by `<kd-chart>` and activated via `type="customDendrogram"`.

The plugin owns its own layout, edge drawing, and node rendering. Labels are delegated to **chartjs-plugin-datalabels** so they pick up theme tokens (and remain readable on dark backgrounds).

## Features

- Vertical, horizontal, and radial orientations
- Solid, palette-colored nodes (no border by default), one color per top-level branch
- Optional icon (URL or inline SVG markup) rendered inside each node
- Configurable arrow direction on connecting lines: `none`, `forward`, `reverse`, or `both`
- Hover scale-up animation
- Click-to-expand/collapse subtrees with smooth position + opacity tweens
- Theme-aware datalabels (color/background/font come from `options.plugins.datalabels`)

## Usage

```html
<kd-chart
  type="customDendrogram"
  .datasets=${[
    {
      label: 'Tree',
      data: [
        { name: 'Root' },
        { name: 'Child A', parent: 0 },
        { name: 'Child B', parent: 0 },
      ],
    },
  ]}
  .options=${{
    colorPalette: 'categorical',
    plugins: {
      customDendrogram: {
        orientation: 'vertical',
        direction: 'forward',
      },
    },
  }}
></kd-chart>
```

### Tree node shape

Each entry in the dataset's `data` array is a node:

| Field       | Type                                         | Description                                                                                                                                         |
| ----------- | -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`        | `string \| number`                           | Optional. Unique identifier for the node. Defaults to the array index if omitted.                                                                   |
| `name`      | `string`                                     | Required. Used for the rendered label and tooltip.                                                                                                  |
| `parent`    | `string \| number`                           | References the `id` of the parent node (or array index for backward compat). Omit for the root.                                                     |
| `icon`      | `string`                                     | Optional. Either a URL/data URL or an inline `<svg>...</svg>` markup string.                                                                        |
| `direction` | `'none' \| 'forward' \| 'reverse' \| 'both'` | Optional. Overrides the global `direction` for the edge connecting this node to its parent. Useful for showing mixed arrow styles in a single tree. |

The first entry without a `parent` is treated as the root.

## Plugin configuration options

All options live under `options.plugins.customDendrogram`. Defaults shown.

| Option              | Type                                         | Default         | Description                                                                             |
| ------------------- | -------------------------------------------- | --------------- | --------------------------------------------------------------------------------------- |
| `orientation`       | `'vertical' \| 'horizontal' \| 'radial'`     | `'vertical'`    | Layout direction.                                                                       |
| `tree`              | `Array<{name, parent?, icon?}>`              | `[]`            | Alternative to dataset `data`. Same shape as the dataset entries.                       |
| `direction`         | `'none' \| 'forward' \| 'reverse' \| 'both'` | `'none'`        | Arrowheads on edges. `forward` = parent→child, `reverse` = child→parent, `both` = both. |
| `expandable`        | `boolean`                                    | `true`          | Enables click-to-toggle subtree collapse.                                               |
| `animationDuration` | `number` (ms)                                | `350`           | Duration of expand/collapse position + alpha tween.                                     |
| `hoverScale`        | `number`                                     | `1.2`           | Multiplier applied to node radius on hover.                                             |
| `nodeRadius`        | `number` (px)                                | `14`            | Base node radius.                                                                       |
| `nodeFill`          | `string \| null`                             | `null`          | Override node fill. `null` uses the categorical palette per top-level branch.           |
| `nodeStroke`        | `string`                                     | `'#3d3c3c'`     | Border color (only drawn if `nodeStrokeWidth > 0`).                                     |
| `nodeStrokeWidth`   | `number` (px)                                | `0`             | Border width. Default is borderless.                                                    |
| `edgeColor`         | `string`                                     | `'#9a9a9a'`     | Color of connecting lines and arrowheads.                                               |
| `edgeWidth`         | `number` (px)                                | `1.5`           | Line width.                                                                             |
| `arrowSize`         | `number` (px)                                | `9`             | Arrowhead size when `direction !== 'none'`.                                             |
| `iconSize`          | `number` (px)                                | `18`            | Rendered size of node icons.                                                            |
| `palette`           | `string[] \| null`                           | `null`          | Explicit color list. Overrides `paletteKey`.                                            |
| `paletteKey`        | `string`                                     | `'categorical'` | Key into the Shidoka color palettes (e.g. `categorical`, `sequential01`).               |
| `badgeFill`         | `string`                                     | `'#ffffff'`     | Fill color of the "+" badge shown on collapsed nodes.                                   |
| `badgeStroke`       | `string`                                     | `'#3d3c3c'`     | Border + glyph color of the collapsed "+" badge.                                        |
| `padding`           | `number` (px)                                | `40`            | Padding around the layout (currently informational; layout uses normalized data space). |

### Label styling

Labels are rendered by [chartjs-plugin-datalabels](https://chartjs-plugin-datalabels.netlify.app/). Configure them under `options.plugins.datalabels`:

```js
plugins: {
  datalabels: {
    color: 'var(--kd-color-text-level-primary)',
    backgroundColor: 'var(--kd-color-background-container-secondary)',
    font: { size: 12, weight: '500' },
    borderRadius: 2,
  },
}
```

The chart-type defaults already pick the appropriate Shidoka tokens, so labels remain legible on light **and** dark backgrounds out of the box.

## Interaction

- **Hover** — the hovered node scales to `hoverScale` (animated). Cursor switches to a pointer.
- **Click** — toggles the collapsed state of a node with children. Disappearing nodes animate toward their nearest visible ancestor and fade out; reappearing nodes start at the ancestor's position and fade in.

Set `expandable: false` to disable click handling.
